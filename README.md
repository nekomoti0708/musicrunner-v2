# Music Runner v2

Music Runner v2 は、ブラウザ上で動作する高機能でプレミアムなデザインのWebオーディオ＆ビデオプレイヤーです。
ローカルファイルを安全に読み込み、強力なオーディオエフェクトやリアルタイムビジュアライザと共に快適な音楽再生環境を提供します。PWA（Progressive Web App）に対応しており、オフライン環境でも動作します。

---

## 🌟 主な機能

### 1. 安全なローカルファイル・フォルダ読み込み
- **File System Access API (FSA) 対応**: ブラウザからローカルのディレクトリを選択し、直接ファイルを読み込むことができます。権限が許可されれば、次回起動時に「前回のフォルダ」としてすぐに再開可能です。
- **ドラッグ＆ドロップおよびフォルダ選択フォールバック**: FSA 非対応ブラウザやモバイル端末でも、標準の `<input type="file" webkitdirectory>` を用いてフォルダごとファイルを安全に読み込めます。

### 2. 充実したオーディオエフェクト & イコライザー
Web Audio API を活用した、遅延のない本格的なオーディオ調整機能を搭載しています。
- **Bass & Treble**: 低音域・高音域のゲインを個別に調整。
- **Distortion**: 歪みエフェクトにより、音にエッジや温かみをプラス。
- **Reverb**: 臨場感のある残響エフェクト（インパルス応答自動生成）。
- **オーディオプリセット**: `Flat`, `Bass Boost`, `High Treble`, `Lofi`, `Distorted` などの標準プリセットの切り替えに加え、カスタム設定も可能。

### 3. ダイナミックなリアルタイム・ビジュアライザ
- 音楽の周波数スペクトルを解析し、画面下部の Canvas 上にスムーズなグラデーションアニメーションバーとして描画します。
- 音量変化に応じてスケールを自動調整し、どのような音源でも美しい視覚効果を楽しめます。

### 4. プレイリストキューとループ制御
- ファイルツリー of チェックボックスによって、再生リスト（キュー）に含める曲を柔軟に指定できます。
- 単一曲ループとプレイリスト全体のループ再生を切り替え可能です。

### 5. PWA (Progressive Web App) 対応
- Service Worker (`sw.js`) によるオフラインキャッシュに対応。一度読み込めば、インターネット接続がない環境でもローカルプレイヤーとして使用できます。
- Media Session API に対応し、OS側のメディアコントロール（ロック画面や通知領域、キーボードのメディアキー等）からの操作（再生/一時停止/曲送り/曲戻し）が可能です。

## 🛠️ 動作方法

### 必要な環境
ブラウザ環境のみで動作します（サーバーサイドの処理は不要です）。ただし、Service Workerや一部のブラウザAPI（File System Access APIなど）を有効にするため、ローカルで簡易的な HTTP サーバーを立ち上げてアクセスすることを強く推奨します。

### 起動手順

1. **ローカルサーバーの起動**
   プロジェクトディレクトリで、簡易Webサーバーを起動します。
   - 例（Python 3 がインストールされている場合）:
     ```bash
     python -m http.server 8000
     ```
   - 例（Node.js がインストールされている場合）:
     ```bash
     npx http-server -p 8000
     ```
2. **ブラウザでのアクセス**
   起動後、ブラウザで `http://localhost:8000` にアクセスしてください。

## 🚀 使い方

1. **ファイル/フォルダーを開く**
   - ホーム画面で「ファイルを開く」または「フォルダーを開く」をクリックし、ローカルの音楽・動画ファイルが格納されたディレクトリを指定します。
2. **プレイヤー画面**
   - 音楽ファイルの場合はレコード盤風のアニメーションが表示され、動画ファイルの場合はメディアエリアにビデオが再生されます。
   - 画面の下半分を上スワイプ（またはドラッグ）すると、読み込んだフォルダーのファイルツリー構造が表示されます。
   - 右上の「エフェクト」アイコンをクリックすると、イコライザーやリバーブの調整パネルが開きます。
