# Music Runner v2

Music Runner v2 は、ブラウザ上で動作する高機能でプレミアムなデザインのWebオーディオ＆ビデオプレイヤーです。
ローカルファイルを安全に読み込み、強力なオーディオエフェクトやリアルタイムビジュアライザと共に快適な音楽再生環境を提供します。PWA（Progressive Web App）に対応しており、オフライン環境でも動作します。

---

## 🌟 実装済みの機能

### 1. ファイル・フォルダーの読み込み
- File System Access API に対応したブラウザーでは、音楽・動画ファイルを複数選択、またはフォルダー単位で読み込めます。
- フォルダー選択は読み書きモードで権限を要求し、読み込み途中に編集権限を再要求しません。
- FSA 非対応ブラウザーやモバイル端末では、`<input type="file">` と `webkitdirectory` によるフォールバックを使用します。
- 対応する音声形式: `mp3`, `wav`, `m4a`, `ogg`, `flac`, `aac`
- 対応する動画形式: `mp4`, `webm`, `mkv`, `mov`
- フォルダーは再帰的にスキャンし、メディアファイルを含まないフォルダーは一覧から除外します。
- 読み込み中はオーバーレイ、スキャン件数、エラー表示を提供します。
- IndexedDB に FSA のフォルダーハンドルを保存し、「前回のフォルダーを開く」から再利用できます。
- 同一セッションでは、フォールバックで読み込んだファイルもキャッシュして再利用できます。

### 2. ファイルツリー
- フォルダーを先に、その後にファイルを表示します。
- 名前順または `musics.json` の保存順で表示します。
- フォルダーの開閉状態を保持し、スクロール時は現在のフォルダー名を上部に表示します。
- 音声ファイルと動画ファイルでアイコンを切り替えます。
- 再生中のファイルを一覧上でハイライトします。
- ルート直下、フォルダー直下のファイルを一括選択できます。
- 一括選択は全選択、未選択、中間状態を表示します。

### 3. 再生とプレイリスト
- チェックボックスで再生キューへの追加・除外を切り替えます。
- 再生、一時停止、前の曲、次の曲に対応します。
- キューはファイルツリーの深さ優先順に従います。
- ファイルの並べ替え後は再生キューを即時再構築します。
- プレイリストループと単一曲ループを切り替えられます。
- 再生位置、曲名、フォルダー名、総時間、経過時間を表示します。
- 音声はレコード盤風のプレースホルダー、動画は動画表示領域で再生します。
- 音量を調整でき、音量設定は保存されます。
- Media Session API により、OS のロック画面、通知領域、キーボードのメディアキーから操作できます。

### 4. ファイル・フォルダーの並べ替えと移動
- マウスのドラッグ、またはタッチ端末の約 450ms 長押しでドラッグを開始します。
- 行の上半分・下半分に挿入位置ラインを表示します。
- 同じ階層内で前後に並べ替えられます。
- フォルダー行へドロップすると、そのフォルダーへ移動します。
- フォルダー自身を子孫フォルダーへ移動する操作は拒否します。
- 移動後はファイルパス、チェック状態、開閉状態、再生中ファイル、再生キューを更新します。
- 移動後の行は FLIP アニメーションで滑らかに再配置します。
- FSA の `move()` 対応環境では直接移動します。
- `move()` 非対応環境では、ファイルをコピーしてから元を削除します。フォルダーは中身を再帰コピーしてから元を削除します。

### 5. フォルダーごとの JSON 保存
- 各フォルダー直下に `musics.json` を自動作成します。
- `items` に直下のファイル・フォルダーと表示順を保存します。
- `checkedFiles` に直下ファイルのキュー選択状態を保存します。
- `openFolders` に直下フォルダーの開閉状態を保存します。
- ルートの JSON に最後に再生したファイルと再生位置を保存します。
- JSON にない新しい項目は既存項目の後ろへ追加します。
- FSA 環境ではフォルダー状態の正本として JSON を使用します。
- FSA を使えないフォールバック環境では、ブラウザーから実ファイルや JSON を書き込めないため LocalStorage を使用します。

```json
{
   "version": 2,
   "items": [
      { "name": "track.mp3", "kind": "file", "index": 0 },
      { "name": "Disc 2", "kind": "directory", "index": 1 }
   ],
   "checkedFiles": {
      "track.mp3": true
   },
   "openFolders": {
      "Disc 2": true
   },
   "lastPlayedFile": "track.mp3",
   "lastPlayedTime": 12.5
}
```

### 6. オーディオエフェクト
- Web Audio API によるリアルタイム音声処理を使用します。
- Bass: 低音域を調整します。
- Treble: 高音域を調整します。
- Distortion: 歪みを追加します。
- Reverb: 自動生成したインパルス応答による残響を追加します。
- Dynamics Compressor で音量変化を整えます。
- プリセットを選択できます。プリセットは `audio-presets.js` で管理します。
- スライダーを変更すると Custom 設定として保存します。
- エフェクト設定は LocalStorage に保存し、次回起動時に復元します。

### 7. リアルタイムビジュアライザ
- AnalyserNode で周波数スペクトルを解析します。
- Canvas にグラデーション付きのバーを描画します。
- 画面幅に応じてバー数を調整します。
- 音量に応じて最大高さを自動調整します。
- 画面サイズ変更時に Canvas をリサイズします。
- 再生画面下部の設定アイコンから専用設定パネルを開けます。
- ビジュアライザーの表示・非表示を切り替えられます。
- 縦棒の `Vertical Bars` と、細い発光線・透明な下側の塗りを組み合わせた `Aurora Line` を切り替えられます。
- 音の波を上下に広げた半透明のリボンと発光ラインを組み合わせた `Nebula Ribbon` も選べます。
- `Violet Pulse`, `Aqua Signal`, `Sunset Heat`, `Mono Light`, `Cosmic Blue`, `Mint Glow`, `Ember Rose` のカラーパレットを選べます。
- 感度・立ち上がり・戻り速度は、1本の「反応」スライダーで連動調整できます。
- 反応を下げると穏やかで控えめに、上げると音の変化へ素早く強く反応します。
- ビジュアライザー設定は LocalStorage に保存し、次回起動時に復元します。

### 8. タッチ操作と画面操作
- メディア領域を下方向へスワイプしてファイルツリーパネルを開けます。
- パネルヘッダーを上方向へスワイプして閉じられます。
- エフェクトパネルはボタンで開閉できます。
- エフェクトパネルは右方向へのスワイプでも閉じられます。
- 読み込み中は操作を遮るローディングオーバーレイを表示します。

### 9. PWA とオフライン対応
- Service Worker (`sw.js`) でアプリ本体をキャッシュします。
- HTTPS またはローカル HTTP サーバー上では Service Worker を登録します。
- `manifest.json` により PWA としてインストールできます。
- アプリのアイコンとテーマカラーを定義しています。

## 🛠️ 動作方法

### 必要な環境
ブラウザ環境のみで動作します（サーバーサイドの処理は不要です）。ただし、Service Workerや一部のブラウザAPI（File System Access APIなど）を有効にするため、ローカルで簡易的な HTTP サーバーを立ち上げてアクセスすることを強く推奨します。

### 起動手順

1. **ローカルサーバーの起動**
   プロジェクトディレクトリで、簡易Webサーバーを起動します。
   - 例（Python 3 がインストールされている場合）:
     ```bash
     python -m http.server 8000
     ```
   - 例（Node.js がインストールされている場合）:
     ```bash
     npx http-server -p 8000
     ```
2. **ブラウザでのアクセス**
   起動後、ブラウザで `http://localhost:8000` にアクセスしてください。

## 🚀 使い方

1. ホーム画面で「ファイルを開く」または「フォルダーを開く」を選択します。
2. フォルダーを読み込んだ場合は、メディア領域を下方向へスワイプしてファイルツリーを開きます。
3. ファイル行をタップするとそのファイルを選択・再生します。
4. 右端のチェックボックスで再生キューへの追加・除外を切り替えます。フォルダー行のチェックボックスでは直下のファイルを一括操作できます。
5. 並べ替える場合は、行を長押ししてから移動します。マウスではドラッグで操作できます。行の上側・下側に表示されるラインが挿入位置です。
6. フォルダーへドロップすると、そのフォルダーへ移動します。FSA 環境では実ファイルも移動し、`musics.json` が更新されます。
7. エフェクトボタンからプリセット、Bass、Treble、Distortion、Reverb を調整できます。
8. ホームボタンで再生画面を閉じます。前回のフォルダーは、権限が残っていればホーム画面から再度開けます。

## ⚠️ 制約

- File System Access API は主に Chromium 系ブラウザーで利用できます。
- FSA 非対応環境ではファイルを読み込めますが、ディスク上のファイル移動や `musics.json` の作成はできません。
- FSA 環境で実ファイルを移動するには、フォルダーの読み書き権限が必要です。
- Service Worker と PWA は `file://` では利用できないため、ローカル HTTP サーバーまたは HTTPS で起動してください。
